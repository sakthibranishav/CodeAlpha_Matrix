# CodeAlpha_Matrix
# Matrix Operations in C

A menu-driven C console application that performs fundamental matrix operations. This project was developed as part of the **CodeAlpha C Programming Internship** to demonstrate the use of functions, 2D arrays, modular programming, and problem-solving skills.

---

## Features

- Matrix Addition
- Matrix Multiplication
- Matrix Transpose
- Matrix Subration
- Menu-driven interface
- Modular programming using functions
- User-friendly console output
- Input validation for matrix multiplication

---

## Technologies Used

- C Programming
- Functions
- 2D Arrays
- Loops
- Conditional Statements
- Switch Case

## How to Run

1. Clone the repository.

```
git clone https://github.com/your-username/CodeAlpha_Matrix.git
```

2. Open the project in VS Code or any C IDE.

3. Compile the program.

```
gcc matrix.c -o matrix
```

4. Run the executable.

```
./matrix
```
